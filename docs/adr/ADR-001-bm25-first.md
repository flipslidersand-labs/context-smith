# ADR-001: Phase 1〜5 は BM25、Phase 6 でベクトル検索を追加

- **日付**: 2026-06-20
- **状態**: Accepted

## 背景

タスク関連ファイルの検索方法として、BM25 全文検索とベクトル検索（埋め込みモデル）の2択がある。

## 決定

Phase 1〜5 は tantivy の BM25 だけで実装し、Phase 6 でベクトル検索を追加して RRF 統合する。

## 理由

- BM25 は「関数名・型名・変数名」を含むコード検索で十分な精度が出る
- 埋め込みモデルは GPU/CPU コストが高く、Phase 1 から入れると環境依存が増える
- BM25 の精度限界（同義語・意味的類似度）を実際に体験してから Phase 6 に進める

## トレードオフ

- セマンティック検索（「ログイン処理」で `authenticate()` を見つける等）は Phase 5 まで弱い
