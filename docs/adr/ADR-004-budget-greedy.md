# ADR-004: トークン予算配分にグリーディー法を使う

- **日付**: 2026-06-20
- **状態**: Accepted

## 背景

BM25 スコアで順位付けされたファイル群を、トークン上限 N に収めるアルゴリズムが必要。
厳密な最適化（ナップサック問題）とグリーディー近似の選択肢がある。

## 決定

スコア降順にファイルを並べ、トークン累積が `budget` を超えるまで貪欲に選択するグリーディー法。

## 理由

- ナップサック厳密解は NP 困難で、ファイル数が多いと現実的でない
- コードのコンテキスト選択では「スコアが高いものを優先する」直感と一致するためグリーディーで十分
- 実装がシンプルで `--explain` フラグによる選択理由の出力がしやすい

## トレードオフ

- 「スコアは低いが小さいファイルを多く入れた方が総合的に良い」ケースを最適化できない
  → Phase 6 以降でスコア × (1/tokens) の密度スコアで改善を検討
